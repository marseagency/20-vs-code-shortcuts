انتخاب و Multi-Cursor

انتخاب همزمان تمام کلمات مشابه

Windows
Ctrl + Shift + L
macOS
Cmd + Shift + L
عملکرد

تمام نمونه‌های کلمه یا عبارت انتخاب‌شده را در فایل انتخاب می‌کند و برای همه آن‌ها Cursor قرار می‌دهد.

const user = "Ali"; console.log(user); const admin = user;
مثال

اگر روی user باشید و این شورت‌کات را بزنید، تمام userهای مشابه انتخاب می‌شوند و می‌توانید همه را همزمان تغییر دهید.

کاربرد

تغییر نام کلاس، متغیر، متن یا هر عبارت تکرارشده در یک فایل.

انتخاب مرحله‌ای کلمات مشابه

Windows
Ctrl + D
macOS
Cmd + D
عملکرد

هر بار که این میانبر را فشار می‌دهید، تطابق بعدی عبارت انتخاب می‌شود.

const user = "Ali"; console.log(user); console.log(user);
تفاوت با شماره ۱

Ctrl + Shift + L تمام موارد مشابه را انتخاب می‌کند، اما Ctrl + D به‌صورت مرحله‌ای جلو می‌رود.

کاربرد

زمانی که فقط بعضی از موارد مشابه باید تغییر کنند.

مثال

می‌توانید در پنج خط مختلف Cursor ایجاد کنید و یک متن را همزمان در همه خطوط بنویسید.

مثال

در ابتدای چند خط یک متن مشابه اضافه کنید. با Column Selection می‌توانید چند خط را همزمان ویرایش کنید.

چند تفاوت مهم که بهتر است به خاطر بسپارید

Ctrl + D در مقابل Ctrl + Shift + L

Ctrl + D → انتخاب موارد مشابه به‌صورت مرحله‌ای
Ctrl + Shift + L → انتخاب تمام موارد مشابه

Alt + ↑ / ↓ در مقابل Shift + Alt + ↑ / ↓

Alt + ↑ / ↓ → جابه‌جایی خط
Shift + Alt + ↑ / ↓ → تکثیر خط

Ctrl + F در مقابل Ctrl + Shift + O

Ctrl + F → جست‌وجوی متن
Ctrl + Shift + O → پیدا کردن Symbolهای فایل

F2 در مقابل Find & Replace

F2 → تغییر نام یک Symbol بر اساس ساختار کد
Find & Replace → جست‌وجو و جایگزینی متن

Ctrl + / در مقابل Shift + Alt + A

Ctrl + / → Comment خطی
Shift + Alt + A → Comment بلوکی

Ctrl + G در مقابل Ctrl + P

Ctrl + G → رفتن به شماره خط
Ctrl + P → پیدا کردن فایل
